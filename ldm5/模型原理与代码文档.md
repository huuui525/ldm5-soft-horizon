# 五通道地震数据潜在扩散模型 (LDM5) — 原理与代码详解

---

## 一、模型整体架构概述

LDM5 是一个**两阶段潜在扩散模型 (Latent Diffusion Model)**，用于五通道地震图像数据的生成与重建。模型遵循 Stable Diffusion / LDM 的核心范式：

1. **第一阶段（AutoencoderKL）**：训练一个 VAE 自编码器，将五通道地震图像从像素空间 `[5, 224, 224]` 压缩到低维潜在空间 `[8, 56, 56]`，空间压缩比为 **4 倍**。
2. **第二阶段（Latent DDPM）**：在潜在空间中训练一个 U-Net 噪声预测器（DDPM），学习去噪过程，从而实现高质量的地震数据生成。

| 组件 | 输入形状 | 输出形状 | 参数量（约） |
|------|----------|----------|-------------|
| AutoencoderKL 编码器 | `[B, 5, 224, 224]` | `[B, 8, 56, 56]` | ~3-5M |
| AutoencoderKL 解码器 | `[B, 8, 56, 56]` | `[B, 5, 224, 224]` | ~3-5M |
| Latent U-Net | `[B, 8, 56, 56]` | `[B, 8, 56, 56]` | ~10-20M |

### 3.1 自编码器构建 (`build_autoencoder`)

```python
def build_autoencoder(cfg: AEConfig) -> AutoencoderKL:
```

使用的配置（`config.py:22-30`）：
```python
@dataclass
class AEConfig:
    in_channels: int = 5           # 5 个地震属性通道
    out_channels: int = 5
    latent_channels: int = 8       # 潜在空间通道数
    block_out_channels = (64, 128, 256)  # 3 个编码/解码块
    layers_per_block: int = 2      # 每块 2 层残差卷积
    downsample_factor: int = 4     # 空间下采样倍数
```

**架构细节**：
- 编码器：3 个 `DownEncoderBlock2D`，通道数依次为 64 → 128 → 256
- 下采样只在 block 之间进行（非每个 block），共下采样 2 次，每次 2 倍，总计 4 倍
- 解码器：3 个 `UpDecoderBlock2D`，对称上采样
- 潜在空间：8 通道，空间尺寸为 224 / 4 = 56

**下采样因子的验证逻辑**：
```python
# models.py:22-28
n_blocks = len(cfg.block_out_channels)       # 3
expected_factor = 2 ** (n_blocks - 1)         # 2^2 = 4
```

`n` 个 block 之间进行 `n-1` 次下采样（每次 2 倍），因此最终缩放因子为 `2^(n-1)`。

**U-Net 结构特点**：
- 4 个下采样块 + 1 个中间块 + 4 个上采样块
- 第 3 个下采样和第 2 个上采样块包含**自注意力层 (Self-Attention)**，用于捕获长程依赖
- 输出与输入同形状 `[B, 8, 56, 56]`
- 接收时间步嵌入作为条件输入

### 3.3 DDPM 调度器 (`build_scheduler`)

```python
# models.py:57-61
def build_scheduler(cfg: TrainConfig) -> DDPMScheduler:
    return DDPMScheduler(
        num_train_timesteps=1000,       # 1000 步扩散过程
        prediction_type="epsilon",      # 预测噪声 ε（而非 x0 或 v）
    )
```

- **`prediction_type="epsilon"`**：模型学习预测添加到干净潜变量中的**噪声 ε**
- 前向扩散：`x_t = √(ᾱ_t) * x_0 + √(1-ᾱ_t) * ε`，其中 `ᾱ_t` 随 t 递减
- 反向去噪：`x_{t-1} = 1/√(α_t) * (x_t - (1-α_t)/√(1-ᾱ_t) * ε_θ(x_t, t)) + σ_t * z`

## 六、训练流程

### 6.1 第一阶段：训练自编码器 (`train_autoencoder.py`)

```
训练循环（每个 epoch）:
  for step, batch in enumerate(DataLoader):
      1. batch → Encoder → 潜在分布 μ,σ
      2. z ~ N(μ, σ)  （重参数化采样）
      3. z → Decoder → 重建图像
      4. loss = L1_recon + λ₁*grad_loss + λ₂*corr_loss + λ₃*freq_loss + 1e-6*KL
      5. 计算 PSNR（归一化数据上的 MSE → dB）
      6. 反向传播（AMP 混合精度 + GradScaler）
      7. TrainLogger 记录每步指标
  end_epoch: TrainLogger 输出 epoch 汇总均值
```

**关键实现细节**：

- **PSNR 监控**（`train_autoencoder.py:127-129`）：在归一化数据上计算 `10*log10(1/MSE)` 作为重建质量的代理精度指标，随 loss 一同记录。
  ```python
  with torch.no_grad():
      mse = torch.nn.functional.mse_loss(recon.float(), batch.float())
      psnr = 10.0 * torch.log10(1.0 / (mse + 1e-12))
  ```
- **TrainLogger 集成**：记录的字段为 `["total", "recon", "grad", "kl", "psnr"]`。
- **进度条增强**：kl 值使用科学计数法单独格式化显示（`{kl:.2e}`），其余指标保留 4 位小数。

训练细节：
- **混合精度训练**：使用 `torch.amp.autocast("cuda", dtype=torch.float16)` + `GradScaler` 加速训练
- **优化器**：AdamW，学习率 `1e-4`，权重衰减 `0.0`
- **批次大小**：4（默认）
- **KL 权重**：`1e-6`（最小化正则化对重建质量的影响）
- 每 5 个 epoch 保存一次检查点，训练结束保存到 `outputs/autoencoder/final/`

### 6.2 第二阶段：训练潜在扩散模型 (`train_latent_diffusion.py`)

```
训练循环（每个 epoch）:
  for step, batch in enumerate(DataLoader):
      1. batch → 冻结的 Encoder（AMP 推理）→ 干净潜变量 z₀
      2. 采样噪声 ε ~ N(0,I)
      3. 采样时间步 t ~ Uniform(1,T)
      4. 前向扩散：z_t = scheduler.add_noise(z₀, ε, t)
      5. U-Net 预测（AMP）：ε_θ = unet(z_t, t)
      6. loss = MSE(ε_θ, ε)
      7. 反向传播（GradScaler）+ AdamW 优化
      8. TrainLogger 记录每步 loss
  end_epoch: TrainLogger 输出 epoch 汇总均值
```

**关键实现细节**：

- **AMP 混合精度训练**：使用 `GradScaler` + `autocast`，编码阶段和 U-Net 前向传播均在 FP16 下执行，显著降低显存和加速计算。
  ```python
  # train_latent_diffusion.py:88 — 初始化 GradScaler
  scaler = torch.amp.GradScaler("cuda", enabled=use_amp)

  # train_latent_diffusion.py:121 — 编码阶段使用 AMP 推理
  with torch.no_grad(), torch.amp.autocast("cuda", dtype=torch.float16, enabled=use_amp):
      latents = ae.encode(batch).latent_dist.sample()

  # train_latent_diffusion.py:131-146 — U-Net 前向 + 反向传播使用 GradScaler
  with torch.amp.autocast("cuda", dtype=torch.float16, enabled=use_amp):
      pred = unet(noisy_latents, timesteps).sample
      loss = F.mse_loss(pred, target)
  scaler.scale(loss).backward()
  scaler.step(optim)
  scaler.update()
  ```
- **cuDNN benchmark 开启**（`train_latent_diffusion.py:50`）：`torch.backends.cudnn.benchmark = True`，让 cuDNN 在固定输入尺寸下自动寻找最优卷积算法。
- **TrainLogger 集成**：记录字段为 `["loss"]`，日志和 CSV 输出到 `outputs/logs/latent_diffusion/`。
- **`global_step` 跨 epoch 递增**：全局步数计数器不随 epoch 重置，便于追踪整个训练过程中的指标变化。

训练细节：
- **自编码器完全冻结**：`ae.eval()` + `requires_grad_(False)`
- **时间步采样**：每批次随机采样 1000 个时间步的子集
- **推理时自动适配**：根据实际编码的潜变量形状动态调整 U-Net 的 `sample_size` 和通道数
- 每 5 个 epoch 保存一次检查点，训练结束保存到 `outputs/latent_diffusion/final/`

## 八、评估模块 (`evaluate.py`)

评估脚本加载已训练的 AE 和 LDM 检查点，从两个维度定量评估模型质量。

### 8.1 自编码器评估 (`evaluate_ae`)

```python
# evaluate.py:71-107
@torch.no_grad()
def evaluate_ae(ae, dataset, channels, mean, std, args):
```

**评估流程**：
1. 遍历训练集前 `num_eval_batches` 个 batch（默认 24 批）
2. 逐样本**确定性编码**（使用 `latent_dist.mode()` 而非采样，消除随机性）
3. 对每个通道**独立计算**四项指标

**四项指标及实现**：

| 指标 | 计算方式 | 代码位置 |
|------|----------|----------|
| **L1** | `abs(pred - target).mean()` | `evaluate.py:88` |
| **MSE** | `(pred - target)^2.mean()` | `evaluate.py:89` |
| **PSNR** | `10*log10(data_range^2 / MSE)` | `evaluate.py:32-34, 91-92` |
| **SSIM** | 单尺度结构相似度（无高斯窗） | `evaluate.py:37-48, 93` |

**PSNR 函数**（`evaluate.py:32-34`）：
```python
def psnr(pred, target, data_range):
    mse = torch.mean((pred - target) ** 2)
    return 10.0 * torch.log10((data_range ** 2) / (mse + 1e-12))
```
不同于训练时在归一化数据固定 `data_range=1` 计算 PSNR，评估时使用**每个 batch 中目标通道的实际 min/max 范围**作为 `data_range`，使 PSNR 值反映原始物理量纲下的重建精度。

**SSIM 函数**（`evaluate.py:37-48`）：
```python
def ssim_2d(pred, target, data_range):
    c1 = (0.01 * data_range) ** 2   # 亮度稳定常数
    c2 = (0.03 * data_range) ** 2   # 对比度稳定常数
    # 计算均值、方差、协方差
    # SSIM = (2μ₁μ₂+c1)(2σ₁₂+c2) / (μ₁²+μ₂²+c1)(σ₁²+σ₂²+c2)
```
实现的是简化版单尺度 SSIM（不使用高斯滑动窗），对整个图像计算全局均值和方差。范围为 [0, 1]，越接近 1 表示结构相似度越高。

**输出报告**：每个通道的 L1 / MSE / PSNR / SSIM，以及跨通道的 L1/PSNR/SSIM 均值。

### 8.2 潜在扩散模型评估 (`evaluate_ldm`)

```python
# evaluate.py:110-155
@torch.no_grad()
def evaluate_ldm(ae, unet, scheduler, dataset, channels, args):
```

**评估流程**：

1. **真实分布统计**：在训练集上计算每个通道的像素均值 `real_mean` 和标准差 `real_std`（归一化空间内）
   ```python
   # evaluate.py:113-123
   for batch in loader:
       real_means[c] += batch[:, c].mean()
       real_stds[c] += batch[:, c].std()
   ```

2. **DDPM 逆向采样**（`evaluate.py:126-133`）：
   ```python
   scheduler.set_timesteps(args.num_inference_steps)  # 设置推理步数（默认 50）
   latents = torch.randn(sample_shape)                  # 从纯噪声开始
   for t in scheduler.timesteps:
       pred = unet(latents, t).sample                   # U-Net 预测噪声
       latents = scheduler.step(pred, t, latents).prev_sample  # 一步去噪
   images = ae.decode(latents).sample                   # 解码到像素空间
   ```
   这与训练时的循环不同：训练时每个 batch 随机采样单个时间步，推理时需要**完整的 T→1 链式去噪**（从纯高斯噪声逐步去噪到干净潜变量）。

3. **生成分布统计**：计算生成样本每个通道的均值 `gen_mean` 和标准差 `gen_std`

4. **分布偏差指标**：
   - `mean_abs_diff`：`|gen_mean - real_mean|` 的五通道均值 — 衡量生成样本在**中心趋势**上与真实数据的一致性
   - `std_abs_diff`：`|gen_std - real_std|` 的五通道均值 — 衡量生成样本在**数据分散程度**上与真实数据的一致性

**输出**：JSON 报告（`outputs/evaluation/report.json`），包含各通道真实/生成统计量及偏差指标；同时将归一化空间的生成样本保存为 `.npy` 文件供可视化使用。

### 9.1 核心绘图函数

**单图绘制**（`visualize.py:44-51`）：
```python
def imshow_panel(ax, img, title, cmap):
    vmin, vmax = np.percentile(img, [2, 98])  # 使用 2%-98% 分位数裁剪色域
```

```python
def grid_figure(maps, channels, row_labels, save_path, suptitle, cmap):
```

## 十二、模型原理总结

### 为什么使用两阶段架构？

1. **计算效率**：在 `56×56` 的潜在空间做扩散比在 `224×224` 的像素空间直接做扩散，计算量减少约 16 倍（空间维度缩小 4 倍，面积为 1/16）。

2. **感知压缩**：自编码器将高维像素数据压缩为语义上有意义的低维潜在表示，扩散模型只需学习潜在空间的分布，而非原始像素分布。

3. **生成质量**：LDM 架构已在图像生成领域得到广泛验证，结合了 VAE 的压缩能力和扩散模型的生成质量。

### 地震数据的特殊处理

- **多通道物理属性**：5 个通道对应不同的地球物理属性（速度、密度、伽马等），它们之间存在岩石物理关系
- **梯度损失**：专门设计用于保留地震反射界面和断层等**边缘特征**
- **每通道独立归一化**：不同属性的数值范围差异巨大（如速度 vs 伽马值），独立 Z-score 归一化确保每个通道被平等对待

### 训练基础设施

- **AMP 混合精度**：两阶段训练均使用 `torch.amp.autocast(dtype=float16)` + `GradScaler`，在保持训练精度的同时降低约 40% 显存占用并加速计算
- **cuDNN benchmark**：固定输入尺寸下自动搜索最优卷积实现
- **结构化日志**：`TrainLogger` 同时输出 `.log` 文本日志和 `.csv` 表格，每个训练运行独立存储于带时间戳的目录中，支持后续可视化和对比分析
- **PSNR 监控**：自编码器训练阶段实时计算 PSNR（峰值信噪比），作为重建质量的直观参考

### 评估体系

- **AE 逐通道定量评价**：L1/MSE/PSNR/SSIM 四项指标，按通道分别报告，识别各属性的重建难度差异
- **LDM 分布级评价**：通过比较真实与生成样本的均值和标准差，从分布一致性角度评估生成质量
- **可视化验证**：三张 PNG 网格图（真实/重建/生成），使用反归一化后的原始物理单位，支持肉眼定性判断
- **所有输出可复现**：固定种子、保存原始数组，确保结果可追溯
