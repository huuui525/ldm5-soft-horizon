# LDM5 六通道层位条件方案优化结果

---

## 一、优化目标

原始层位条件方案只使用一张共享层位响应图：

```text
shared_horizon = mean(vertical_gradient(dn, gas, gr, vp, vs))
```

这种做法稳定，但会把五个物性通道各自的边界差异平均掉。本次优化改为默认使用六通道条件：

```text
condition = [
  shared_horizon,
  dn_horizon,
  gas_horizon,
  gr_horizon,
  vp_horizon,
  vs_horizon
]
```

其中：

- `shared_horizon` 表示五通道共同的层位结构；
- `dn_horizon` 到 `vs_horizon` 表示每个通道自身的深度方向突变响应。

该方案希望同时保留“共同地质层位”和“各属性通道的局部差异”。

---

## 二、代码改动

| 文件 | 改动 | 作用 |
|------|------|------|
| `horizon.py` | 新增 `per_channel_horizon_maps`、`combined_horizon_maps`、多通道 label 函数 | 支持 `[B,5,H,W]` 和 `[B,6,H,W]` 条件图 |
| `conditional_unet.py` | `HorizonAdapter` 支持任意条件通道数，`MultiScaleHorizonUNet` 默认 `condition_channels=6` | U-Net 可以接收六通道条件 |
| `train_horizon_latent_diffusion.py` | `--condition_mode` 默认改为 `combined`，自动探测条件通道数 | 训练时默认启用六通道条件 |
| `visualize_horizon_diffusion.py` | 默认 `combined` + `jet`，新增 `--conditions_only` | 可先单独可视化六通道条件图 |
| `.gitignore` | 新增 `outputs_six_channel_horizon/` | 忽略六通道实验输出 |

---

## 三、支持的条件模式

| 模式 | 输出形状 | 含义 |
|------|----------|------|
| `soft` | `[B,1,H,W]` | 原始共享软层位图 |
| `label` | `[B,1,H,W]` | 原始共享二值层位图 |
| `per_channel` | `[B,5,H,W]` | 五个通道分别计算软层位图 |
| `per_channel_label` | `[B,5,H,W]` | 五个通道分别计算二值层位图 |
| `combined` | `[B,6,H,W]` | 共享软层位图 + 五通道软层位图 |
| `combined_label` | `[B,6,H,W]` | 共享二值层位图 + 五通道二值层位图 |

推荐优先使用：

```text
--condition_mode combined
```

---

## 四、预期效果

六通道条件相比原始一通道条件，理论上会带来以下收益：

1. **更强的通道特异性**
   - `vp/vs/dn/gas/gr` 各自的边界响应不会被平均抹平。

2. **更好的结构控制**
   - 共享层位负责整体地质结构，单通道层位负责属性细节。

3. **更适合分析五通道同步与差异**
   - 可视化时能直接看到每个通道对层位的贡献。

同时也有代价：

- 条件通道数从 1 增加到 6，条件分支参数量略有增加；
- 单通道层位图可能带入更多噪声；
- 需要重新训练条件 U-Net，旧的一通道 checkpoint 不能直接用于六通道生成。

## 七、判断是否更好的指标

建议不要只看生成图片是否“更好看”，而是同时比较：

| 指标 | 目的 |
|------|------|
| 条件图与生成图的层位响应 L1 | 判断生成是否跟随条件 |
| 各通道 vertical edge L1 | 判断单通道边界是否清晰 |
| 通道相关矩阵差异 | 判断五通道物性关系是否保持 |
| 频谱差异 | 判断生成纹理是否接近真实 |
| 专家视觉检查 | 判断层位连续性和地质合理性 |

如果六通道条件有效，预期现象是：

- 生成图的层位边界更贴近条件图；
- 各通道边界更清楚，不再只表现为平均层位；
- `dn/gas/gr/vp/vs` 的差异性更明显；
- 共享结构仍保持连续，不出现明显碎裂。

---

## 八、结论

本次优化已经将层位条件从单一共享图扩展为默认六通道条件。它兼顾了共同层位结构和五个属性通道的独立响应，是比原始方案更有表达能力的条件形式。

需要注意的是，六通道条件改变了 U-Net 的条件输入维度，因此必须重新训练 `MultiScaleHorizonUNet`。旧的一通道条件 checkpoint 可以作为 baseline 对比，但不能直接用于 `combined` 模式生成。
